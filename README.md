## Descripción del Sitio
Sitio web informativo desarrollado para la Feria de Innovación Tecnológica de la institución. Cuenta con cuatro páginas principales orientadas a la presentación del evento, exhibición de proyectos tecnológicos, programación de actividades y un apartado de contacto e inscripción para los asistentes.

## Tecnologías Utilizadas
* **HTML5:** Estructuración semántica de las páginas web.
* **CSS3:** Hoja de estilos propia y externa (`css/styles.css`) con diseño y colores personalizados.
* **Bootstrap 5:** Utilizado de apoyo para componentes visuales.
* **Git y GitHub:** Herramientas de control de versiones y repositorio remoto colaborativo.

## Instrucciones para Ejecutar o Visualizar
1. Clonar este repositorio o descargarlo como archivo ZIP en su equipo local.
2. Descomprimir el proyecto (si se descargó en ZIP) y abrir la carpeta completa en un editor de código.
3. Buscar el archivo **`index.html`** en la carpeta principal.
4. Hacer doble clic en el archivo `index.html` o abrirlo con cualquier navegador web para visualizar el sitio completo y navegar entre sus secciones.
